# results/

Versioned, schema-validated machine-readable outputs. All data is simulated.

- `exploratory/<config>/`: exploratory runs only (labelled so in every file). Never evidence for a hypothesis.
- `confirmatory/<config>/`: written only after the owner freezes the protocol. Holds the frozen EXP-001 to EXP-003 runs (1,560 of 1,560 ok, 2026-11-24) and their frozen analysis in `confirmatory/analysis/`.
- `raw/`: git-ignored, regenerated by script.

Each run directory holds `results.json` (schema 1.0.0), `run_manifest.json`, `metrics.csv`, `summary.json`, `evidence_manifest.json` (SHA-256 of every generated output), `report.md`, `report.pdf` and `figures/`.
